🌲 Endless Runner Integration

This parallax background is designed to seamlessly integrate into any HTML5/JS endless runner loop:

// 1. Initialize in your game
const bg = new AutumnParallaxBackground(canvas);

// 2. In your game loop:
function loop(timestamp) {
  const dt = (timestamp - lastTime) / 1000;
  
  // Update background movement
  bg.update(dt);
  
  // Draw background first
  bg.draw();
  
  // Draw your runner character & obstacles
  player.draw(ctx);
  obstacles.draw(ctx);
  
  requestAnimationFrame(loop);
}

💡 Tip: Call bg.setSpeed(newSpeed) as the game speeds up over time! You can also use bg.getGroundY(player.x) to accurately align your character onto the path.
